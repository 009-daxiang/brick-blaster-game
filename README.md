# 暴击砖块 · 长蛇砖阵 100 关

> 横板打砖块 × 贪吃蛇的混血 HTML5 小游戏：**数字格串成一条会游走的长蛇**，球撞蛇身后随机偏转，
> 打碎蛇鳞掉落五种炫目技能。单文件、零外部资源：Canvas 手绘 + WebAudio 实时合成音效，双击 `index.html` 即玩。

## 一、核心玩法

```
点击发射 → 球撞上蛇身削减鳞片数字（反弹角度随机偏转）
   ↑                                  ↓
球全部掉落 = -1 命（共 3 条）    蛇鳞归零碎裂，概率掉技能胶囊
   ↓                                  ↓
命尽 = 本关失败          横板接住胶囊释放技能 · 蛇鳞全清 = 过关
```

- **长蛇砖阵**：蛇头带路游走、蛇身逐节跟随，在高地范围内自由巡游；蛇头有眼睛会发光
- **随机偏转**：每次撞击在物理反射基础上再随机旋转 ±26°，弹道无法预测，压迫感与新鲜感并存
- **星级**：按剩余生命评 1~3★（一球未失 3★），逐关解锁 + localStorage 进度存档

## 二、五种技能（打碎蛇鳞随机掉落，横板接住释放）

| 胶囊 | 技能 | 效果 |
|---|---|---|
| 🟠 分 | 弹球分裂 | 场上每颗球一分为二，最多 9 颗 |
| 🔴 火 | 火球穿透 | 8 秒内球变火球：穿透蛇身不反弹，每次接触烧 3 点血 |
| 🔵 光 | 激光扫射 | 6 秒内横板自动双发激光束，持续削减上方蛇鳞 |
| 🟡 雷 | 天雷连锁 | 8 秒内每碎一片蛇鳞，闪电自动连锁劈向最近的 2 片 |
| 🟣 陨 | 陨石雨 | 立即召唤 6 颗追踪陨石轰击蛇身，溅射伤害 |

每 8 次碎鳞保底掉一个，另有 8% 概率额外掉落。

## 三、100 关难度曲线

- 蛇长 13 → 40 节；蛇鳞血量 1 → 11+；游走速度 51 → 170 px/s；转向越来越频繁
- 球速 520 → 800；**弹板每过 20 关缩小一档**（宽度系数 2.5 → 1.7）
- 每关由关卡号作种子生成（同一关蛇的起点方向/血量分布固定）
- 第 100 关通关有专属彩蛋文案

## 四、操作

| 平台 | 操作 |
|---|---|
| 手机 / 触屏 | 用 `mobile.html`：屏幕任意处左右滑动控板，点按发射 |
| 电脑 | 鼠标移动控板，点击 / 空格发射，← → 也可移动，Esc 暂停 |

## 五、技术要点

- 单 HTML 文件；蛇采用"跟随引导链"算法（每节追前一节保持定距），天然形成游走曲线
- 球 vs 旋转鳞片采用 OBB 碰撞（转入鳞片局部坐标系求交），反弹法线精确
- 反弹后强制最小垂直分量（0.25×球速），杜绝近水平死循环
- 每帧 2 次子步碰撞防穿透；高分屏适配；音效全部 WebAudio 合成；手机端震动反馈

# 暴击砖块 · 横板打砖块 100 关

> 经典**横板打砖块（Breakout / Arkanoid）**玩法的 HTML5 复刻，融合 BBTAN 式连击音阶，外加"砖阵下压"的压迫感机制。
> 单文件、零外部资源：砖块全部 Canvas 手绘，音效 WebAudio 实时合成，双击 `index.html` 即玩（手机浏览器也可）。

## 一、核心玩法

```
点击发射 → 球弹向砖阵削数字 → 横板左右移动接球反弹
   ↑                                ↓
球全部掉落 = -1 命（共 3 条）   砖块归零碎裂；「0」号砖掉「分裂」
   ↓                                ↓
命尽 = 本关失败     砖阵持续下压：压到与弹板平行 = 直接失败
                          砖块全清 = 过关（按剩余生命评 1~3★）
```

两条失败线，双重压迫感：
1. **接球线**：球全部掉落扣一条命，3 条命扣光失败；
2. **时间线**：砖阵从进场起就以每关递增的速度持续下压（第 1 关约 3px/s，第 100 关约 11px/s），最低一排砖压到与弹板平行时**立即失败**（无论剩几条命）。迫近时屏幕泛红光 + 警报音。

## 二、「0」号砖与唯一技能：分裂

- 每关砖阵里随机藏着一块紫色发光的**「0」号砖**（显示数字 0，一碰即碎），位置由关卡种子决定，每关都不一样；
- 打碎它必掉「分裂」道具，横板接住后场上每颗球一分为二（上限 9 颗）；
- **多球规则**：分裂后掉下来，接住任意一颗就继续，其余掉落不扣命；只有全部掉光才 -1 命；
- 全游戏只有这一个技能。

## 三、"打击感"分层设计

| 层 | 手感目标 | 实现手段 |
|---|---|---|
| 预判层 | 看得清落点 | 球体发光拖尾（加色混合）、待发射虚线提示 |
| 接触层 | 撞得上 | 砖块受击闪白、数字弹跳放大、横板受击压扁回弹 |
| 反馈层 | 打得痛 | 碎块飞屑（重力+旋转）、震屏力度随砖块硬度、音高随连击爬升的合成音效 |
| 奖赏层 | 越打越爽 | 连击 ≥4 接板时结算"连击 ×N"奖励分、分裂多球、最后一块砖慢动作、过关彩带+星级 |

## 四、100 关设计

- 每关由关卡号作**种子**生成（同一关布局固定）：8 种砖阵图案轮换（全排/棋盘/边框/金字塔/菱形/条纹/锯齿/散点）
- 难度四维爬坡：行数 3→8、砖块血量 1→11+、球速 520→800、**砖阵下压速度 3→11 px/s**
- **弹板每过 20 关缩小一档**（宽度系数 2.5 → 2.3 → 2.1 → 1.9 → 1.7）
- 全清过关解锁下一关，按剩余生命评星（一球未失 3★ / 失 1 球 2★ / 其余 1★），进度存 localStorage
- 第 100 关通关有专属彩蛋文案

## 五、操作

| 平台 | 操作 |
|---|---|
| 手机 / 触屏 | 左右拖动控制横板，点击发射 |
| 电脑 | 鼠标移动控制横板，点击 / 空格发射，← → 也可移动，Esc 暂停 |

## 六、技术要点

- 单 HTML 文件，`requestAnimationFrame` 主循环 + 每帧 2 次子步碰撞（圆-矩形反弹，防穿透）
- 反弹后强制校验最小垂直分量，杜绝水平死循环
- 砖阵下压通过全局偏移量 `boardY` 实现，碰撞与渲染共用同一坐标函数，缩放窗口不串位
- 高分屏适配（devicePixelRatio）、触屏 `touch-action:none` 防误滚；音效全部 WebAudio 合成；手机端震动反馈

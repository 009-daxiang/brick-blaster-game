# 暴击砖块 · 枪火长蛇 100 关

> 打砖块 × 贪吃蛇 × 弹幕射击的混血 HTML5 小游戏：小枪手在底部持枪扫射一条会游走下压的
> 长蛇数字阵，子弹不反弹、打中即消除，六种炫彩子弹技能随便切。单文件、零外部资源：
> Canvas 手绘 + WebAudio 实时合成音效，双击 `index.html` 即玩。

## 一、核心玩法

```
按住屏幕持续射击 → 子弹打中蛇鳞造成伤害后消失（不反弹）
      ↑                        ↓
左右移动小枪手走位      蛇鳞归零碎裂，概率掉炫彩技能胶囊
      ↓                        ↓
长蛇持续加速下压        接住胶囊换弹 · 蛇鳞全清 = 过关
      ↓
蛇压到枪手位置 = 失败（右侧进度条实时显示压境程度）
```

- **长蛇**：蛇头带路游走、蛇身跟随，越往后越长（19 → 50 节）、越快（72 → 260 px/s）、越频繁转向，并且整条蛇持续向下压境
- **星级**：按"最小安全距离"评 1~3★——蛇离枪手越远时过关，星级越高；进度存 localStorage

## 二、六种炫彩子弹技能（碎鳞掉落，按住枪手接住激活）

| 胶囊 | 技能 | 效果 |
|---|---|---|
| 🟢 散 | 三向散射 | 子弹呈扇形三连发 |
| 🟠 火 | 火焰弹 | 命中溅射：波及 64px 内所有蛇鳞 |
| 🟣 穿 | 穿透弹 | 子弹穿过蛇身连续伤害多片 |
| 💗 追 | 追踪弹 | 子弹自动拐弯咬住最近的蛇鳞 |
| 🔵 速 | 速射模式 | 射速提升 2.3 倍 |
| 🌈 彩 | 彩虹弹 | 子弹七彩变色，伤害随机 1~3 |

每种持续 8 秒，可同时叠多个 buff；每 7 次碎鳞保底掉一个，另有 8% 概率额外掉落。

## 三、100 关难度曲线

- 蛇长 19 → 50 节；蛇鳞血量 1 → 12+；数字格随关卡更小更密
- 游走速度 72 → 260 px/s；下压速度 2.6 → 8.5 px/s；转向越来越刁钻
- 第 100 关通关有专属彩蛋文案

## 四、操作

| 平台 | 操作 |
|---|---|
| 手机 / 触屏 | 按住屏幕任意处：左右滑动 = 移动枪手，按住不放 = 持续射击 |
| 电脑 | 鼠标移动 = 走位 + 按住左键射击，或 ← → 移动 + 空格射击，Esc 暂停 |

## 五、技术要点

- 单 HTML 文件；蛇为"跟随引导链"，球…子弹 vs 旋转蛇鳞用 OBB 精确碰撞
- 子弹穿行模式带逐鳞冷却防多次判定；追踪弹用受限角速度转向，弹道自然
- 高分屏适配、触屏 `touch-action:none`；音效全部 WebAudio 合成；手机端震动反馈
